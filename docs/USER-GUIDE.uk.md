# MultiFrame Browser — Інструкція користувача

**Мова:** Українська · [English](USER-GUIDE.en.md)

MultiFrame Browser — десктопний застосунок для Windows, що запускає від 1 до 9 незалежних вебсесій одночасно в одному вікні, у сітці. Кожна сесія («профіль») має власне сховище, власний проксі й власний відбиток ідентичності пристрою — тож ззовні дев'ять профілів в одному вікні виглядають як дев'ять різних людей на дев'яти різних комп'ютерах.

Ця інструкція описує, як користуватись застосунком. Про те, які дані він зберігає й надсилає, — у [Політиці конфіденційності](PRIVACY-POLICY.uk.md). Про умови використання — в [Ліцензійній угоді (EULA)](EULA.uk.md).

## 1. Встановлення

Доступні два типи збірки:

- **Інсталятор (`MultiFrame Browser-<версія>-setup.exe`)** — звичайний NSIS-інсталятор. Дозволяє обрати теку встановлення, створює ярлики в меню «Пуск».
- **Portable (`MultiFrame Browser-<версія>-portable.exe`)** — один файл, що запускається одразу, без встановлення. Дані лишаються при самому файлі (або там, де Windows тримає дані портативних застосунків на цій машині), а не у вашому звичайному профілі користувача — зручно для запуску з флешки або повної ізоляції від решти системи.

Жодна зі збірок наразі не підписана сертифікатом підпису коду. Windows SmartScreen може показати попередження «нерозпізнаний застосунок» при першому запуску — це очікувано, доки сертифікат не отримано (внутрішньо відслідковується, не ознака підміни файлу). Натисніть **Докладніше → Однаково виконати**, якщо довіряєте джерелу, звідки завантажили файл.

## 2. Перший запуск

При першому запуску з'явиться екран **Launcher**:

1. Оберіть кількість профілів (1–9). Це визначає форму сітки (наприклад, 4 профілі — сітка 2×2, 9 — 3×3).
2. Якщо є збережена попередня сесія, стане доступний чекбокс **«Відновити попередню сесію»** — позначте його, щоб знову відкрити ті самі адреси й профілі, що були минулого разу.
3. Натисніть **Відкрити робочу область**.

Холодний старт до готової сітки зазвичай займає кілька секунд.

## 3. Робоча область

Кожна комірка сітки — окремий профіль. У кожної своя панель інструментів:

| Елемент | Призначення |
|---|---|
| Назва профілю | Зліва, кольорове маркування для кожного профілю |
| ← / → | Назад / вперед в історії цього профілю |
| ⟳ / ✕ | Оновити сторінку, або зупинити завантаження, поки воно триває |
| Адресний рядок | Введіть адресу й натисніть Enter |
| ⌕ | Пошук на сторінці (недоступний, доки не відкрито сторінку) |
| ⚙ | Інструменти розробника для цієї вкладки (недоступний, доки не відкрито сторінку) |
| − / 100% / + | Масштабування цього профілю |
| Позначка режиму проксі | Показує чинний режим з'єднання (Direct / HTTPS / SOCKS5) |
| ▢ / ▣ | Розгорнути комірку на все вікно, або повернутись до сітки |

**Комірка без введеної адреси навмисно порожня** («Введіть адресу, щоб почати») — реальна сесія браузера для цього профілю не створюється, доки ви фактично кудись не перейдете. Це прискорює старт і зменшує споживання пам'яті, коли всі профілі одразу не потрібні.

**Неактивні профілі засинають.** Профіль, який не чіпали приблизно 10 хвилин (і який не в фокусі й не розгорнутий), автоматично звільняє свою сесію браузера, щоб вивільнити пам'ять. Клік по ньому чи введення адреси знову відкриває ту саму адресу — ви не помітите нічого, крім короткого перезавантаження.

## 4. Гарячі клавіші

Працюють навіть тоді, коли фокус клавіатури всередині сайту в одному з фреймів:

| Клавіші | Дія |
|---|---|
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Наступний / попередній фрейм |
| `Ctrl+M` | Розгорнути / повернути фокусований фрейм |
| `Alt+←` / `Alt+→` | Назад / вперед |
| `Ctrl+R` або `F5` | Оновити |
| `Ctrl+F` | Пошук на сторінці |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Збільшити / зменшити / скинути масштаб |
| `Ctrl+,` | Відкрити налаштування |

## 5. Налаштування

Відкрийте Налаштування кнопкою внизу праворуч вікна, або клавішами `Ctrl+,`.

### Профілі

Кожен профіль можна:
- **Перейменувати** — клік по назві.
- **Перефарбувати** — клік по кольоровій крапці.
- **Дублювати** — створює новий профіль зі **свіжою** ідентичністю пристрою (ніколи не копію відбитка — два профілі з однаковим відбитком зводили б нанівець сенс ізоляції). Якщо у вихідного профілю призначено проксі, копія зберігає ту саму відповідність країни для таймзони/локалі.
- **Скинути** — стирає всі збережені дані (cookies, логіни, усе) цього профілю. Неможливо скасувати.
- Перевірити **обсяг на диску**, або лише очистити кеш, не чіпаючи cookies/логіни.

**Зберігати сесію (persist session)** — коли увімкнено, cookies й сховище профілю переживають закриття застосунку. Коли вимкнено — усе для цього профілю зникає одразу після закриття чи скидання. Перемикання перезавантажує фрейм профілю й відкидає те, що було в ньому відкрито.

**Резервна копія / відновлення** — профіль (разом із cookies й логінами) можна експортувати в зашифрований файл `.mfbackup`, захищений паролем, який ви самі обираєте, і відновити пізніше — навіть на іншому комп'ютері. Це навмисно відрізняється від власного сховища облікових даних Windows, яке прив'язане саме до цього ПК й облікового запису Windows і не переноситься.

**Проксі** — розгорніть цю секцію, щоб призначити профілю проксі:
- Оберіть **Direct** (без проксі), **HTTPS** або **SOCKS5**.
- Введіть хост, порт і, за потреби, логін/пароль.
- **Перевірити** перевіряє проксі й показує його exit-IP, країну, ASN, тип підмережі та оцінку анонімності/якості.
- **Призначити** застосовує його до профілю — це відбувається навіть якщо проксі зараз недосяжний (можна наперед налаштувати те, що ще не піднято); якщо дані перевірки містять країну, таймзона й локаль профілю автоматично підлаштовуються під неї.

### Самоперевірка

Проганяє набір перевірок для обраного профілю **зсередини** реальної сторінки, яку він показує, — звіряючи те, що профіль заявляє (User-Agent, таймзона, розмір екрана, GPU тощо), з тим, що сторінка фактично може спостерігати. **Це детектор невідповідностей, а не «оцінка анонімності»** — гонитва за «ідеальним балом» в іншому місці сама по собі є розпізнаваним патерном.

### Безкоштовні проксі

Для вставки списку адрес `host:port` (по одній на рядок) і перевірки їх з вашого прямого з'єднання. Прочитайте попередження про ризики перед використанням цієї вкладки: значна частина публічних проксі існує для перехоплення трафіку, тому проксі звідси можна призначати лише профілю з вимкненим збереженням сесії й порожнім сховищем — ця вкладка для перевірки роботи застосунку, не для входу в реальні акаунти. Прийняті результати можна одразу призначити профілю просто з цієї вкладки.

### Платні проксі

Короткий перелік проксі-провайдерів, придатних для роботи з кількома профілями, з чесною позначкою, коли провайдер здебільшого пропонує датацентрові підмережі (які частіше блокуються). Це партнерські посилання — клік по них відкриває системний браузер за замовчуванням, ніколи профіль усередині застосунку, тож жодні трекінгові cookies провайдера не потрапляють у ваші профілі.

### GeoIP

MultiFrame Browser може визначати країну/місто/ASN проксі через **локальну** базу MaxMind GeoLite2, а не через хмарний сервіс запитів. Щоб скористатись:

1. Створіть безкоштовний обліковий запис на [maxmind.com](https://www.maxmind.com/) і отримайте ліцензійний ключ GeoLite2.
2. Вставте його в поле ліцензійного ключа тут і натисніть **Зберегти**.
3. Натисніть **Завантажити / оновити базу**.

Нічого не завантажується, доки ви не надасте власний ключ, і єдиний мережевий запит цієї функції — саме завантаження бази, напряму на офіційний сервер MaxMind.

### Підтримка

Адреси для необов'язкового донату проєкту в кількох криптовалютах. Відкриття цього вікна не породжує жодного мережевого запиту; адреси вбудовані в застосунок, ніколи нізвідки не завантажуються. Звіряйте будь-яку адресу повністю (не лише перші/останні символи) перед надсиланням — шкідливе ПЗ, що підміняє адреси в буфері обміну, існує саме для цього.

### Мова / Тема

Перемикання мови інтерфейсу відбувається миттєво, без перезавантаження жодного відкритого фрейму, і — що важливо — не змінює те, яку мову жоден профіль повідомляє сайтам, які відвідує. Доступні темна й світла теми; це виключно налаштування оболонки, жодного стосунку до профілів.

## 6. Усунення проблем

| Симптом | Ймовірна причина |
|---|---|
| Комірка показує сторінку мережевої помилки | Сторінка не завантажилась — перевірте адресу або призначений проксі |
| Комірка показує помилку проксі й жодна сторінка не завантажується | Призначений проксі недоступний. Застосунок навмисно **не** переходить на ваше реальне з'єднання в цьому випадку — це і є сенс проксі. Виправте чи перепризначте проксі цього профілю. |
| Комірка показує помилку сертифіката | Не вдалось перевірити TLS-сертифікат сайту. Профілі з тестовим (безкоштовним) проксі ніколи не можуть прийняти виняток для сертифіката — це навмисно, бо безкоштовний проксі з прийнятим поганим сертифікатом отримує повну позицію «людина посередині» над вашою сесією. |
| Кнопки DevTools/Пошук виглядають сірими | У комірці ще немає відкритої сторінки — спершу введіть адресу |
| Попередження SmartScreen при запуску | Очікувано, доки застосунок не підписано сертифікатом (див. вище) |
